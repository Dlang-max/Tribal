# Task 1 implementation report

## Implemented

- Added Python 3.12 package metadata and direct dependency pins in `pyproject.toml` and `requirements.txt`, with a pinned transitive `requirements.lock`. FastMCP is pinned to 4.1.6; PyPI's small `fastmcp` wheel delegates to `fastmcp-slim==4.1.6`, and the expected imports work from the installed package.
- Added validated environment settings in `src/tribal/settings.py`. `Settings.from_env()` loads `PUBLIC_BASE_URL`, `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET`, `TOKEN_SIGNING_KEY`, and the optional worker values `PROJECT_ID`, `PROJECT_NAME`, and `ALLOWED_GITHUB_IDS`. `SESSION_SIGNING_KEY` is optional at parse time so workers do not need the browser-session secret; `add_management_session_middleware()` requires it for the management app.
- Added FastMCP GitHub OAuth worker in `src/tribal/project_worker.py`. Exports: `build_project_worker(settings)`, `create_project_context(settings)`, `ProjectAccessMiddleware`. Public MCP route is `/projects/{uuid}/mcp`; FastMCP OAuth operations are under `/projects/{uuid}`; project-scoped metadata routes at the host root are `/.well-known/oauth-authorization-server/projects/{uuid}` and `/.well-known/oauth-protected-resource/projects/{uuid}/mcp`. FastMCP's child lifespan is forwarded, and `/healthz` and `/readyz` are public health routes.
- The tool is named `get_project_context`, accepts no arguments, and returns `id`, `name`, `sample: true`, and sample context text. The middleware reads the verified FastMCP access-token `sub` and checks the numeric GitHub account ID against the worker allowlist on every tool call.
- Added Authlib management browser auth in `src/tribal/authentication.py`. Exports: `GitHubIdentity`, `build_management_auth_routes(settings)`, `add_management_session_middleware(app, settings)`, `get_current_user(request)`, `require_current_user(request)`, `csrf_token_for(request)`, and `verify_csrf_token(request, submitted_token)`. Routes are `/auth/login`, `/auth/callback`, and `/auth/logout`. Callback identity is fetched from GitHub `/user`; only positive numeric GitHub IDs are accepted. Sessions use signed HttpOnly SameSite=Lax cookies; mutation integrations can use the session-bound CSRF helpers, and logout requires `X-CSRF-Token`.

## Checks performed

- Created `.venv`, installed dependencies, and editable-installed the project from `pyproject.toml`.
- Imported the modules and started the worker through Uvicorn locally with sample credentials/configuration.
- HTTP smoke checks returned 200 for `/healthz`, `/readyz`, both project-scoped root metadata URLs, and 405 for a GET to `/projects/{uuid}/mcp` (the MCP transport endpoint accepts POST).
- Confirmed FastMCP 4.1.6 source supports project-path-aware issuer metadata through `auth.get_well_known_routes('/mcp')` and the implemented routes are generated by the library.
