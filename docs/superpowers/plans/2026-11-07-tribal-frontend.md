# Tribal frontend implementation plan

Goal: Simple clean template frontend with presentation-matched styling.
Spec: approved conversation plan; detailed page designs are placeholders.
Global constraints: React/TypeScript/Vite, Tailwind/shadcn, React Flow; source/assets src/, tests tests/. Inter regular/bold; background #09080D, panels #251833, accent #A67AFF, accent text #100B18, text #F4F0FA, muted #C6BBD3. Local sample data only; graph inspection only; no backend/auth/editing. npm lockfile. All writers in separate worktrees and descriptive branches, frequent focused commits. Implementors never write tests; testers never edit application code. Parent coordinates independent implementation and test reviews up to three rounds each; unresolved findings block completion.

Task 1: Foundation. Own root tool configuration, src/shared/, src/main.tsx initial bootstrap. Configure React TS Vite Tailwind shadcn aliases React Flow and npm. Provide shared graph types and navigation IDs; document interfaces for consumers. Test tooling Vitest, Testing Library, jsdom and Playwright configured by foundation but tests authored by tester. All test setup under tests/. Scripts dev/typecheck/build/test/test:e2e. Avoid future imports until integration.
Task 2: Theme. Own src/theme/. Bundle Inter regular/bold/license from /home/daniel-lang/Desktop/UB_Hacking_2026/Presentation/assets/fonts/. Global theme variables, responsive basics, focus. Export index.css.
Task 3: Controls. Own src/components/ui/. shadcn-style accessible Button, Input, Card, Tabs and Select using existing installed primitives, theme variables; avoid speculative controls.
Task 4: Shell. Own src/app/. Default export App accepts optional knowledgeExplorer ReactNode prop. Local nav Overview, Repositories, Agents and Tasks, Knowledge Explorer, Settings. Clean sample templates, responsive header/nav, sample labels, no fake live integrations. Consume shared controls/theme without changing other owners' files; parallel missing imports acceptable until integration.
Task 5: Graph. Own src/features/knowledge-explorer/. Default/named export KnowledgeExplorer. Two sample project graphs, search/filter, pan/zoom/fit, node/edge field inspector, keyboard-accessible alternative list, project change clears selection/filter. src/shared types. Relation domain only source/target, UI edge IDs separate. No connection creation/editing.
Task 6: Integration. Own src/main.tsx and minimal cross-feature integration fixes. Wire theme shell explorer, run typecheck/build/manual browser accessibility responsive checks; document run instructions. Fresh implementor/tester and independent reviews.

Each tester owns tests/task-N/. Foundation tester may correct test config only. Integration tester covers browser flows with Playwright; use installed Chromium when available. Independent reviewers inspect frozen code/test commits in their own worktrees; report spec and quality green light or concrete defects. Preserve dependencies; never push or publish.
